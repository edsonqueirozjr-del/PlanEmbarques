Banco de datos y estructura

Persistencia en la nube (Firebase)

Los datos importados, cadastros, usuarios, perfiles, planes e histórico se guardan en Cloud Firestore, compartidos en tiempo real entre todos los usuarios y dispositivos. El acceso se autentica con Firebase Authentication (las contraseñas nunca pasan por este código). localStorage conserva solamente preferencias visuales del dispositivo.
